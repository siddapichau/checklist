03

Design editável

Três temas, cada um com claro e escuro

Operação Azul

Azul profundo + ciano: confiança e leitura rápida.

Turno Âmbar

Grafite + laranja: energia para alertas e prioridades.

Estoque Verde

Verde esmeralda + lilás: sensação de progresso.

No Admin, cada tema deve salvar tokens CSS (cor primária, fundo, texto, raio, fonte), variante claro/escuro, logo, favicon, ordem/visibilidade dos itens do menu e textos da marca. Aplicar via data-theme e data-mode; sem editar código.

Iframe sem perder acessibilidade: o shell define o menu e carrega a página em um iframe. Use postMessage para atualizar título, breadcrumb e altura; valide event.origin. Como alternativa futura, adote um router SPA para deep-link e melhor SEO.

05

Firebase e segurança

O que configurar antes de publicar

Stack recomendada

Firebase Authentication (e-mail/senha + Google), Firestore para dados estruturados, Storage para WebP e Cloud Functions para ações privilegiadas. RTDB pode manter presença/notificações em tempo real.

A configuração enviada identifica o projeto, mas a chave web não é um segredo. O segredo é proteger Firestore/Storage com regras e App Check.

Regra de ouro da IA

Nunca coloque a API key DeepSeek em IA.html ou em firebase.js. O Admin grava uma referência segura; uma Cloud Function chama a API, limita uso, registra auditoria e remove dados sensíveis.

// senha: 8+, maiúscula, minúscula, 2 números e símbolo
/^(?=.*[A-Z])(?=.*[a-z])(?=(?:.*\d){2,})(?=.*[^A-Za-z0-9]).{8,}$/
// também: bloquear, rate-limit, validar tamanho e sanitizar o editor HTML
06

Benchmark

Ideias aproveitadas de apps populares

Todoist e TickTick

Captura rápida, linguagem natural para datas, recorrência, prioridades, etiquetas, filtros salvos, hábitos e calendário. Adaptar para “Nova atividade” em poucos toques.

Trello

Quadro Kanban visual: colunas Pendente → Analisando → Em andamento → Finalizada, etiquetas e checklist dentro do cartão. Excelente para o status operacional.

Asana e ClickUp

Responsáveis, subtarefas, dependências, timeline, comentários, anexos, dashboards e log de atividade. Usar somente o essencial para não sobrecarregar a operação.

Notion

Base de conhecimento flexível: arquivos, posts e categorias com editor rico. Permitir visualização lista/grade/calendário sem duplicar os dados.

Microsoft To Do / Google Tasks

Interface leve, “Meu dia”, sincronização e offline. Inspirar o modo turno: mostrar somente o que é relevante hoje, com ação rápida “concluir”.

Motion / Sunsama

Planejamento por blocos de tempo e sugestão de agenda. Na IA, oferecer recomendação, mas exigir confirmação humana — a operação nunca deve ser alterada automaticamente.

Pesquisa consultada: Todoist · Trello · Asana · Notion · Microsoft To Do
